Core Engineering Challenges & Solutions

Multi-Tenant Isolation

Designed a shared-database, tenant-isolated MongoDB architecture. Custom Express middleware extracts and verifies the tenantId on every API request, automatically scoping all Mongoose queries to prevent any cross-tenant data access.

Razorpay Split Payouts

Integrated Razorpay Route API to handle composite student fees in a single checkout, automatically splitting payouts between the school's account, transportation vendor, and extracurricular fees with instant webhook reconciliation.

4-Tier RBAC Security

Implemented strict Role-Based Access Control spanning Super Admins, School Administrators, Teachers, and Parents/Students. Protected routes validate JWT claims and permission scopes before resolving controllers.

Attendance & Analytics

Engineered daily automated attendance tracking, instant parent notifications, report card generators, and administrative dashboards with real-time class summaries.

Problem Statement & Architectural Overview

Educational institutions traditionally face severe administrative friction managing disjointed workflows: attendance in physical ledgers, fee collections processed manually across disparate bank accounts, and lack of real-time communication between teachers and parents. Furthermore, existing off-the-shelf software solutions often lack multi-tenancy, requiring dedicated server deployments per school.

ShikshaNetra was architected from the ground up to solve these challenges as a scalable, cloud-native Multi-Tenant Software-as-a-Service (SaaS). By using isolated schema logic in MongoDB and role-scoped JWT authentication, multiple educational institutions can operate safely on a single infrastructure cluster with guaranteed data partitioning and zero cross-tenant leakage.

Key Capabilities Shipped

  • Automated Split Payment Flow: Parents pay composite semester fees online; Razorpay Route automatically settles tuition to the school treasury, transport charges to bus fleet operators, and lab fees to department sub-accounts in a single compliant transaction.
  • Role-Based Portals: Custom tailored interfaces for School Principals (global KPI monitoring), Teachers (class attendance & grading), and Parents (fee receipts & child progress).
  • Automated Digital Invoicing: Instant PDF receipt generation upon webhook verification of payment completion with tamper-proof reference hashes.
  • Attendance & Schedule Engine: Real-time student tracking with automated SMS/email alerts for unexcused absences.
